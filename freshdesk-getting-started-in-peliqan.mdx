**_Freshdesk_** _is a cloud-based customer support platform, designed to help businesses streamline their helpdesk operations through ticketing systems, automation, and multichannel support. It provides a comprehensive platform for managing customer interactions across various channels, including email, phone, chat, social media, and more. Website:_ [https://www.freshworks.com/freshdesk/](https://www.freshworks.com/freshdesk/)

The Freshdesk Connector in Peliqan enables seamless integration between your Freshdesk data and other business systems, allowing for automated workflows and centralized customer service analytics. This connector is particularly valuable for teams looking to enhance their support operations by connecting ticket data with CRM platforms, business intelligence tools, or custom applications.

This guide provides an overview of setting up the **Freshdesk** Connector in Peliqan. For technical assistance or custom integration requirements, please [contact our support team](https://peliqan.io/contact).

## Prerequisites

- A valid **Freshdesk account** with admin/API access and API Token
- The **instance domain** (your company's Freshdesk subdomain)
- A valid **start date** for data sync

## Configuration Steps

### 1. API Token _(Required)_

- This is your **personal API key** from Freshdesk.
- To find it:
  - Log in to your Freshdesk instance.
  - Click your **profile icon** (top-right corner) → **Profile Settings**.
  - Copy the **API Key** shown on the right.

<img
  src="/images/Freshdesk - Getting started in Peliqan/Screenshot_2025-06-12_at_1.06.05_AM.png"
  alt="Freshdesk API key location"
/>

### 2. Instance Domain _(Required)_

- Format: `https://yourcompany.freshdesk.com`

<img
  src="/images/Freshdesk - Getting started in Peliqan/Screenshot_2025-06-12_at_1.03.18_AM.png"
  alt="Freshdesk instance domain"
/>

### 3. Start Date _(Required)_

- Format: `YYYY-MM-DD` (e.g., `2024-01-01`)
- This defines the **earliest data** the connector will import.

## FreshDesk data sync to a data warehouse

Peliqan offers an out of the box data warehouse. Optionally the user can choose to sync Freshdesk data to their own data warehouse such as Snowflake, Google BigQuery, MS SQL etc.

Data will be synced to the chosen data warehouse and made available through the Peliqan UI for exploration.

<img
  src="/images/Freshdesk - Getting started in Peliqan/redacted-image_(2).png"
