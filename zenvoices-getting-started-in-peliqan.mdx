**_Zenvoices_** _is a modern HR and workforce management platform designed to streamline employee data, time tracking, payroll, and compliance. It provides intelligent software solutions to automate invoice processing for accountants and small to medium-sized businesses (SMEs).It is useful in automating the processing of E-invoices. Website :_ [https://www.zenvoices.com/](https://www.zenvoices.com/)

Zenvoices supports secure API-based access with _organization-specific tenancy name_, ensuring controlled and structured data retrieval. The connector features customizable date ranges, field mappings, and incremental sync options for efficient data handling.This connector is ideal for businesses looking to:

- Automate HR data flows into analytics or ERP systems
- Sync employee records with other business applications
- Ensure real-time updates between Zenvoices and reporting tools

This article provides an overview to get started with the **Zenvoices** connector in **Peliqan**. Please [contact support](https://peliqan.io/contact) if you have any additional questions or remarks.

### **Prerequisites**

- Valid **Zenvoices account** with admin or API access (Navigate to Manage **\>** Organization **\>** Users in the Zenvoices portal. Create/Edit a user and edit permissions of the user to grant API permissions)
- Organization's **tenancy name** (provided by Zenvoices)
- Correct **username/email** and **password**

### **Configuration Steps**

#### **1. Username/Email** **_(Required)_**

- Input the **email address** associated with your Zenvoices account.
- Example: `your.name@company.com`

#### **2. Password** **_(Required)_**

- Enter the **password** for your Zenvoices account.
- Ensure the password is correct to avoid authentication failures.

#### **3. Tenancy Name** **_(Required)_**

- This is your **organization's unique name** available in Zenvoices instance URL
- Example: If your Zenvoices URL is `https://{tenancy-name}.zenvoices.com`, use `{tenancy-nam}`.

#### **4. Start Date** **_(Required)_**

- Format: `YYYY-MM-DD` (e.g., `2025-06-01`).
- This defines the **oldest data** the connector will fetch.
