## Feature list

| Feature | Description |
| --- | --- |
| Federated query engine | Realtime & federated queries |
| Data Explorer (spreadsheet UI) | "Spreadsheet" interface to work with data: view, sort, filter etc. |
| Database & data warehouse connectors | Connectivity to relational and non-relational databases and data warehouses. |
| SaaS connectors | Connectivity to a wide range of business applications (using API connections) |
| Schema discovery | Automatic schema discovery for each source |
| Query editor SQL on anything | Write custom SQL queries, combine data from multiple sources (joins), share the result as new tables |
| Build data apps (low-code) | Build data apps using low-code Python scripting: interactive dashboards, writebacks (reverse ETL), machine learning (predictions, outliers etc.), data monitoring with Slack alerts, etc. |
| BI | Connect any BI tool (Power BI, Tableau, Qlik, Looker, Metabase...) or deploy Metabase from Peliqan Market Place |
| Built-in data warehouse | Set up ETL flows, materialize tables and make them available for access by external BI-tools |
| Bring your own data warehouse | Connect your existing data warehouse (Snowflake, BigQuery, Redshift, Microsoft Fabric etc.) and combine with Peliqan's built-in data warehouse |
| Writeback (reverse ETL) | Sync data back to business apps with the Reverse ETL app (field mapping, scheduling) or with low-code Python scripts. |
| Connector builder | Build your own ETL and writeback connectors or rely on Peliqan connector services to build them for you. |
| On-prem connectivity | Connect to your on-premise data sources with Peliqan Satellite (Windows agent for SQL Server and ODBC databases), a VPN tunnel (NetBird, site-to-site IPSec and others) or IP whitelisting. |
| Lineage | Show provenance of data and impact analysis |
| Publish data APIs | Share data products (built in Peliqan) with other teams as consumable APIs |
| Data masking (PII) | Obfuscate sensitive data using transformations in SQL queries. |
| Import & export data from and to files | Import & export CSV, JSON, Excel, Google Sheet etc. |
| Market place | One-click install of Metabase, Airflow, Apache SuperSet, SuperAgent (build private LLMs), Qdrant vector database etc. |
| Incoming webhook events | Capture incoming webhook events |
| Custom connector builder | Bespoke UI to build custom connectors (private instances only). Missing a connector? [Contact us](/contact-support), our connector team can build a new connector in 2 weeks. |
| Relational model discovery | Detect relational models (FKs) from DB sources and SaaS sources. |
| MCP Servers | Peliqan MCP: ask questions about your business data and work with your business apps from ChatGPT, Claude, Gemini, Copilot or any MCP client. Peliqan Build MCP: manage pipelines and data apps from your AI client. Build custom MCP servers in Python. |
| Peliqan Machines | Build business applications (any language or framework) on Peliqan VMs, with Peliqan as the backend for login, database, business data and writeback. |
| Peliqan AI assistant | Helps write queries, build Data Apps and Machine apps, and analyze pipelines and errors. |
| Semantic models | Add metadata, data models and semantic models so AI agents and BI tools understand your data. |
| Multi-customer management | Partner accounts with a sub account per end customer, white-label and embedding. |
| Excel add-in | Pull live data from Peliqan tables and queries into Excel. |

## Architecture

Peliqan's all-in-one data platform architecture consists of multiple layers, deployed as micro-services in a cloud-agnostic Kubernetes environment:

<img
  src="/images/Feature list and Architecture/peliqan_architecture.png"
  alt="Peliqan architecture diagram"
/>

The UI layer converts all data access to SQL queries that are executed in real-time using Peliqan's federated query engine (Trino) or as direct queries on the DB or DW.
