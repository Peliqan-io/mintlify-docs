**_Exact Globe_** _is an on-premises ERP solution from_ **_Exact_** _designed for small and medium-sized businesses. It provides integrated modules for financial accounting, inventory management, purchasing, sales, manufacturing, project management, and CRM._

This article provides you an overview to get started with **Exact Globe** in Peliqan. Please [contact support](https://peliqan.io/support) if you have any additional questions or remarks.

## How to connect

Install the **Peliqan Satellite Windows data sync agent**. More info:

[Peliqan Satellite - Windows on-prem Data sync Agent](/on-prem-connectivity/peliqan-satellite-windows-on-prem-data-sync-agent)
