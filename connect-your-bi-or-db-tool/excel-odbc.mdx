You can use MS Query or Power Query in Excel to connect to the Peliqan data warehouse.

Note: MS Query and Power Query (with DB connection) are only available in Excel on Windows, not Mac.

<Tip>
As an alternative, you can also use the [Peliqan Excel add-in](/excel-add-in) !
</Tip>

## Enable ODBC in Excel (Legacy)

In Excel &gt; File &gt; Options &gt; Data: enable legacy data import wizards, see screenshot below:

![image](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/6ebe05fa-dfa4-4c4c-ac34-19556f5004e6/excel_options_legacy_data/w=1920,quality=90,fit=scale-down)

## Install Postgres ODBC driver on Windows

Download the Postgres ODBC driver:

[https://odbc.postgresql.org/](https://odbc.postgresql.org/)

Choose the [64 bit version (X64)](https://ftp.postgresql.org/pub/odbc/releases/REL-17_00_0006/psqlodbc_x64.msi) for recent computers.

## Add a DSN

Open ODBC Database Administrator on Windows (64 bit version if you are using a recent computer). Add a User DSN, choose PostgreSQL Unicode:

![image](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/0acf22ff-bcc7-43de-ace6-d50a5531095e/dsn_postgres/w=1920,quality=90,fit=scale-down)

Add the connection details of your Peliqan data warehouse:

![image](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/3e470c5a-3f42-4afe-a63a-510c4db0442a/dsn/w=1920,quality=90,fit=scale-down)

Use "allow" for SSL Mode.

## Add a connection in Excel

In Excel, go to Data &gt; Get Data &gt; From Other Sources &gt; ODBC &gt; Select your DSN.

![image](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/b5ae4894-9502-4015-9903-62b74942e0b8/Schermafbeelding_2025-10-01_111834/w=1920,quality=90,fit=scale-down)

Next, select tables and/or queries from Peliqan to load in Excel.

<Tip>
If you want to work with queries written in Peliqan, make sure to set the option "Create as view" in Peliqan for that query, so that it is visible in the data warehouse and hence in Excel.
</Tip>

The selected tables will be loaded in Excel and can be refreshed at any time:

![image](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/b6ddd1d3-61c9-46cd-829b-927e2f69bc6f/data_in_excel/w=1920,quality=90,fit=scale-down)

You can also use Power Query in Excel.

In Excel go to Power Query &gt; New Source &gt; Other Sources &gt; ODBC &gt; Select your DSN.

![image](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/a691c580-e88a-4266-a861-26c51f925d10/power_query/w=1920,quality=90,fit=scale-down)
