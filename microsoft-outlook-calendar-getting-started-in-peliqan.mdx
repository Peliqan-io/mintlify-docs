This article provides an overview to get started with the **Microsoft Outlook Calendar** connector in **Peliqan**. Please [contact support](https://peliqan.io/contact) if you have any additional questions or remarks.

## Microsoft Outlook Calendar Sync Pipeline

### Connect to Microsoft Outlook Calendar

Connect Microsoft Outlook Calendar through the Peliqan connectivity module:

![Outlook Calendar connection in Peliqan](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/6e714356-5174-44dc-8a6c-c5e31d52f4b5/a0a457dd-1d92-4056-baf8-713e6ccd4a3f/w=1920,quality=90,fit=scale-down)

Configuration options:

- Start Date (required)
- (Optional) table selection via 'Advanced'

Once filled, Click on "Connect Microsoft Outlook Calendar" to initiate OAuth Flow Authentication.

### Microsoft Outlook Calendar data sync to a data warehouse

Peliqan offers an out of the box data warehouse. Optionally the user can choose to sync Microsoft Outlook Calendar data to their own data warehouse such as Snowflake, Google BigQuery, MS SQL etc.

Data will be synced to the chosen data warehouse and made available through the Peliqan UI for exploration.

![Outlook Calendar data in Peliqan Explore](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/0e601547-9e5a-4f77-b1f1-b15995c7258e/image/w=1920,quality=90,fit=scale-down)
