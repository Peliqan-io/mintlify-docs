[**Bloqs**](https://www.bloqsclientvolgsysteem.nl/) is a client tracking and management system developed specifically for care and re-integration organizations. Built with direct input from professionals in the field, Bloqs is designed to streamline your daily operations through smart, user-friendly tools tailored to your workflows.

This article provides an overview to get started with the **Bloqs Software** connector in **Peliqan**. Please [contact support](https://peliqan.io/contact) if you have any additional questions or remarks.

## Connecting to Bloqs

Connect Bloqs through the Peliqan Connectivity module:

<img
  src="/images/Bloqs Software - Getting started in Peliqan/image.png"
  alt="Bloqs connection form"
/>

Configuration options:

- Bi_user
- Bi_key
- Account
- Optional: table selection under 'Advanced'

Once filled, click on **Save** to get the data synced into the data warehouse.

## Bloqs Data Pipeline to Data Warehouse

Peliqan offers an out of the box data warehouse. Optionally the user can choose to sync Bloqs Software data to their own data warehouse such as Snowflake, Google BigQuery, MS SQL etc.

Data will be synced to the chosen data warehouse and made available through the Peliqan UI for exploration.
