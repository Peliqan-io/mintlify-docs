Peliqan allows you to securely connect to on prem (on premise) data sources such as locally installed databases (SQL Server, MySQL, Postgres etc.), on prem business applications and on prem servers using one of the following methods:

- Scenario 1: Open up a port on your on-prem firewall and apply IP Whitelisting
- Scenario 2: Peliqan Satellite, an on-prem Windows agent
- Scenario 3: Set up a peer-to-peer VPN tunnel
- Scenario 4: Set up an IPSec site-to-site VPN tunnel

# Scenario 1: IP Whitelisting

In this scenario, we assume you have an on-prem firewall, you open up a port on the firewall for access by Peliqan, and you whitelist the Peliqan IP addresses so that no one else can connect to the given port. More info:

[IP whitelisting](/ip-whitelisting)

# Scenario 2: Peliqan Satellite

Install Peliqan Satellite on your on-prem Windows server, in order to sync data from an on-prem SQL Server database to your Peliqan data warehouse. More info:

[Peliqan Satellite - Windows on-prem Data sync Agent](/on-prem-connectivity/peliqan-satellite-windows-on-prem-data-sync-agent)

# Scenario 3: Peliqan peer-to-peer VPN tunnel

Peliqan supports self-service activation of the NetBird VPN, a secure software-only VPN that establishes a peer to peer mesh connection between your on-prem server and the Peliqan data cloud. More info:

[NetBird VPN](/on-prem-connectivity/netbird-vpn)

Peliqan also supports a wide range of protocols and VPN vendors, please contact [support](mailto:support@peliqan.io) to request the setup of your custom VPN, examples:

- WireGuard
- OpenVPN
- WatchGuard VPN
- Fortinet VPN (FortiClient/FortiGate)
- TailScale VPN
- Sophos
- And others

# Scenario 4: set up an IPSec site-to-site VPN tunnel

Peliqan supports connectivity to private clouds and on-prem environments through an IPSec site-to-site VPN. More info:

[Site-to-site IPSec VPN](/on-prem-connectivity/site-to-site-ipsec-vpn)
