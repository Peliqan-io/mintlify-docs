_Exact Venice is accounting software designed for Belgian businesses and accounting firms. It supports financial administration, invoicing and statutory reporting, and can handle anything from a single company to large numbers of accounting files._

This article provides you an overview to get started with **Exact Venice** in **Peliqan**. Please [contact support](https://peliqan.io/support) if you have any additional questions or remarks.

## How to connect

Install the **Peliqan Satellite Windows data sync agent** to sync data from Exact Venice installed on-prem, to the Peliqan data cloud. The Peliqan Satellite agent will connect to the Actian Zen database used by Exact Venice.
