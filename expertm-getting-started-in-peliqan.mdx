_Expert/M is a professional accounting software solution designed for accountants, bookkeepers, and SMEs in Belgium. Developed by Wolters Kluwer, the platform offers comprehensive tools for bookkeeping, VAT management, financial reporting, document processing, and client administration._

This article provides you an overview to get started with **Expert/M** in Peliqan. Please [contact support](https://peliqan.io/support) if you have any additional questions or remarks.

## How to connect

Install the **Peliqan Satellite Windows data sync agent**. More info:

[Peliqan Satellite - Windows on-prem Data sync Agent](/on-prem-connectivity/peliqan-satellite-windows-on-prem-data-sync-agent)
