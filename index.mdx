Peliqan is the **Trust layer** for BI and AI. Peliqan provides one-click ETL pipelines from 300+ sources. Peliqan has a built-in data warehouse or you can use your own (Snowflake, BigQuery, Redshift, SQL Server, Fabric etc). Peliqan combines magical SQL with low-code Python to get work done fast, including setting up BI, data activation, vibe coding & publishing Data Apps and APIs, embedding, MCP access and building AI Agents.

<Info>
  **Peliqan MCP:** add Peliqan in ChatGPT, Claude, Gemini, Copilot or any other MCP client. Get instant access to your business data, and interact with your business apps. More info:

  [Peliqan MCP Server](/low-code-python-data-apps/by-protocol-rest-webhooks-mqtt/mcp-model-context-protocol/peliqan-mcp-server)
</Info>
