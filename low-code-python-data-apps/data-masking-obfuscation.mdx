When you process sensitive data such as PII or PHI, you can obfuscate the data so that it is not stored in a readable format in the data warehouse.

This applies e.g. to GDPR and HIPAA compliance.

You can use the Peliqan "Obfuscate data" template to activate data obfuscation (also called data masking) in your data pipelines.

In Peliqan, go to the Build section, search for the "Obfuscate data" template and click on "Use template". Inside the script, add the relevant tables and columns to be masked. Run the script once to apply the masking. Re-run of the selection of tables or columns has changed.
