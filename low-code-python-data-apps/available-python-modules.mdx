Below is a list of modules that are available for import in Peliqan in your Python scripts.

If you need access to another module, please contact [Peliqan Support](https://peliqan.io/contact).

Latest update of the below list: 14 May 2025.

- asyncio
- aiohttp
- aiofiles
- boto3
- dotenv
- extra-streamlit-components
- flask
- folium
- great_expectations
- imgkit
- json
- jsonpath-rw
- marshmallow
- nltk
- openpyxl
- paho-mqtt
- pandas
- peliqan: automatically imported in every script as `pq`
- pdfkit
- psycopg2
- pyarrow
- pymongo[srv]
- pypika
- pysftp
- pyyaml
- requests
- scikit-learn
- sdv
- sqlalchemy
- sqlanydb
- snowflake.connector
- streamlit: automatically imported in every script as `st`
- streamlit modules:
  - streamlit-aggrid
  - streamlit-extras
  - streamlit-folium
  - streamlit_option_menu
  - streamlit_shadcn_ui
- stripe
- superagent-py
- tabulate
- waitress
- xmltodict
- zeep (SOAP client)
