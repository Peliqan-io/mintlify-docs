**_Adsolut_** is an all-in-one accounting and ERP software solution developed for accountants, SMEs, and entrepreneurs in Belgium. Part of the Wolters Kluwer ecosystem, Adsolut helps businesses streamline bookkeeping, invoicing, tax management, reporting, and administrative workflows through a fully digital platform.

This article provides you an overview to get started with **Adsolut** in **Peliqan**. Please [contact support](https://peliqan.io/support) if you have any additional questions or remarks.

## How to connect

Install the **Peliqan Satellite Windows data sync agent**. More info:

[Peliqan Satellite - Windows on-prem Data sync Agent](/on-prem-connectivity/peliqan-satellite-windows-on-prem-data-sync-agent)
