### Generate API Token

1. Create an account on Airtable on [https://www.airtable.com/](https://www.airtable.com/). If account already exist perform **Sign-In.**
2. Once Logged in, navigate to profile at top-right and then to **Developer Hub.**

<img
  src="https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/fc7298be-1fc3-446d-a0ea-14fb7a87bab5/Untitled/w=1920,quality=90,fit=scale-down"
  alt="Airtable Developer Hub navigation"
  style={{ width:"63%" }}
/>

3. Choose "Personal Access Tokens" from left pane under Developers, and then select the "Create Access token" button on the right of the page.
4. Provide a unique name and add **data.records:read, data.records:write, schema.bases:read, schema.bases:write** and **user.email:read** as Scopes.
5. For Access to WorkSpaces and Bases, choose All Workspaces Option.

![Airtable Access Token scopes](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/be85f8b7-0d96-418f-8c09-8c501215baf4/Untitled/w=1920,quality=90,fit=scale-down)

6. Click on "Create Token" button to create an API Access Token..

### Get Base ID

1. Login To [https://www.airtable.com](https://www.airtable.com)
2. Once Logged in create a Base using "Create" button under a WorkSpace.
3. Once created, get into the base and the **BaseID** is visible in the URL just after the base URL i.e. [https://www.airtable.com](https://www.airtable.com)

![Airtable Base ID in URL](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/c5fe84a1-d3e2-4177-ae5c-0045be475b81/Untitled/w=1920,quality=90,fit=scale-down)

### Get Table ID

1. Once you create a table and open it, **table_id** is available just after base_id in the URL.

![Airtable Table ID in URL](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/536039d7-c748-4fff-b0ab-5ea3d2669846/Untitled/w=1920,quality=90,fit=scale-down)

### Get View ID

View ID appears just after the Table ID in the URL once the view is opened.

## Airtable Data Pipelines

Peliqan connects to Airtable performing Basic Authentication using API Access Token. We directly connect to a table to get the records out of the table.

Connect form requires API Access Token, Base_ID, Table_ID to connect to and View_ID ( (optional). View_ID is only required when you need to connect to a particular View.

![Airtable connection form](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/8faa61a6-3ce9-46f6-bbc3-8dd28cc910f7/Untitled/w=1920,quality=90,fit=scale-down)

Once saved, the Data discovery and syncing to DataWarehouse Starts. After syncing completes, all the data tables becomes visible under the Airtable Schema.

![Airtable schema in Peliqan](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/6d4092e2-6136-4a51-aac1-442613ee3631/Untitled/w=1920,quality=90,fit=scale-down)

"Bases" and "Tables" contains metadata of Bases accessible through the API Access Token and all the Tables under them..

Data from the table whose table ID was entered in the connect form appears in "Records" table.

![Airtable Records table](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/a69aa24d-80d5-42c2-9411-df0fd80da302/Untitled/w=1920,quality=90,fit=scale-down)

## Airtable Data Activation

Peliqan provides lot of data activation function which enables users to have different view on data and allows to perform CRUD operations on records.

These methods work when connection to Airtable has already been created.

### Getting Base Schema

"Get Base Schema" method provides the schema of the tables in the specified base. It takes Base_ID as input.

![Get Base Schema method](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/fdd0e394-debd-4d08-bea7-299cc102a083/Untitled/w=1920,quality=90,fit=scale-down)

### Creating a Table

"Add Table" method allows to create a new table under the base. It takes base_id, table name, fields data and description of table as input.

![Add Table form](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/a1d4b1bd-53b0-4e06-8fc7-f5a3c0649a99/Untitled/w=1920,quality=90,fit=scale-down)

![Add Table fields input](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/07ff8fdc-2051-45f3-8175-d793a3f869ff/Untitled/w=1920,quality=90,fit=scale-down)

Reference to "Field types" (AAirtable help):

[https://airtable.com/developers/web/api/field-model](https://airtable.com/developers/web/api/field-model)

### Creating field in a table

"Add Field" table lets users to create a new field to the table. It requires base_id, table_id and field details as input.

![Add Field form](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/9f966f37-f988-4f6a-bcdb-733b7f39931e/Untitled/w=1920,quality=90,fit=scale-down)

### Get all records

"Get Records" method allows users to get all the records from a table. It takes base_id and table_id as input.

![Get Records method](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/01f05057-c1ed-48f1-b149-cf2399fd85ec/Untitled/w=1920,quality=90,fit=scale-down)

### FindOne Record

Method "findone_Record" finds a record based on any field of the table in Airtable. It takes the table_id, base_id, "field_name" as searchfield and "unique data value" as searchterm. Please make sure the field chosen must contain unique values.

![FindOne Record method](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/04222a57-189f-47d6-9aa0-42ff1c9cc45a/Untitled/w=1920,quality=90,fit=scale-down)
