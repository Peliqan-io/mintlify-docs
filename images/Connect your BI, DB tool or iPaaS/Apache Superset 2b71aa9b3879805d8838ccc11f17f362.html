Apache Superset

Apache Superset is an open-source data exploration and visualization platform. It lets you connect to a wide range of databases such as Peliqan’s data warehouse, build interactive dashboards, and share insights with your team. Superset is lightweight, fast, and designed to handle enterprise-scale analytics.

If you don’t have Superset yet, get a Free hosted account on Preset.io.

In Peliqan, go to Connections, find the Data Warehouse tile and copy/paste all connection details:

Use these settings in Apache Supserset to connect:

  • Connection type: Postgres (default data warehouse type in Peliqan)
  • Host:
    • db.eu.peliqan.io
    • db.mydatacloud.com
    • db.us.peliqan.io
    • … (check in your account under Connections > Data warehouse connection)
  • Port: 5432 (for Postgres)
  • User name & password: copy / paste from the Data Warehouse Connection tile (see above)
  • Database name: same as the user name
  • SSL: enabled
