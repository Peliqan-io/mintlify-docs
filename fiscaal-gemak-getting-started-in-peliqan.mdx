**_Fiscaal Gemak_** _is a Dutch cloud-based platform that provides tax and financial services, primarily designed for use by tax advisors, accountants, and businesses. It facilitates digital collaboration for tasks like income tax returns, VAT filings, annual reports, and more. The platform integrates with various accounting and administrative tools and streamlines communication between clients and tax professionals._

_This article provides an overview to get started with the Fiscaal Gemak connector in_ **_Peliqan_**\*. Please\* [_contact support_](https://peliqan.io/contact) _if you have any additional questions or remarks._

# Fiscaal Gemak Data Pipeline

Connect Fiscaal Gemak through the Peliqan Connectivity module:

<img
  src="/images/Fiscaal Gemak - Getting started in Peliqan/Screenshot_2025-08-07_at_13.32.25.png"
  alt="Fiscaal Gemak connection form"
/>

Configuration options:

- Api Key
- Year: the start year to sync data
- Must have deferral: "true" or "false"
- Must have client relation: "true" or "false"
- Declaration type
- Optional: table selection via 'Advanced'

Once filled, click on **Save** to get the data synced into the data warehouse.

# Fiscaal Gemak Data Sync to Data Warehouse

Peliqan offers an out of the box data warehouse. Optionally you can choose to sync Fiscaal Gemak data to your own data warehouse such as Snowflake, Google BigQuery, MS SQL etc.

Data will be synced to the chosen data warehouse and made available through the Peliqan UI for exploration.
