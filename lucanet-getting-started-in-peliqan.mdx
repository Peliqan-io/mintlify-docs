This article provides an overview to connect **Lucanet** to the **Peliqan Data warehouse**. Please [contact support](https://peliqan.io/contact) if you have any additional questions or remarks.

## Connecting Lucanet to Peliqan

In order to sync data from Lucanet into the Peliqan data warehouse, you need to use the Lucanet app "**#4042 - Exporting LucaNet Values for BI Tools**".

More info:

[https://customer.lucanet.com/en/app-for-exporting-lucanet-values-for-bi-tools-4292](https://customer.lucanet.com/en/app-for-exporting-lucanet-values-for-bi-tools-4292)

You can connect your Peliqan data warehouse in the app, choose "Postgres" as the database type in the Lucanet app.

Once the app has exported the data into the Peliqan data warehouse, you can view the data in Peliqan under "Explore".
