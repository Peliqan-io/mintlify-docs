The Peliqan Excel add-in allows you to pull in real-time data from Peliqan into Excel. This can include data in the Peliqan data warehouse, data in an external data warehouse, a connected database, tables created in Peliqan, queries written in Peliqan (including Trino queries using the Peliqan federated query engine).

The Peliqan Excel add-in is a great way to provide self-service access to data for business users. For example, accountants can pull-in real-time data from multiple accounting systems from their end-customers. The add-in is available for Excel on **Windows** and **Mac**, as well as Excel in the **browser**.

<Tip>
  As an alternative, you can also use an ODBC connection in Excel to sync data from Peliqan to Excel sheets. [Click here for more info](/connect-your-bi-or-db-tool/excel-odbc).
</Tip>

## Install the Peliqan add-in in Excel

In Excel go to the Home Ribbon, click on Add-ins and select "More add-ins":

![Excel Home Ribbon add-ins button](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/0ef8eba8-6a58-4828-8ab3-64bb1adbd7bb/Screenshot_2024-06-14_at_15.38.31/w=1920,quality=90,fit=scale-down)

_See "Add-ins" on the right hand side of this Home Ribbon in Excel._

This will open the Add-in Store (Microsoft AppSource). Now search for Peliqan and click on "Add". The add-in will now be added into your Excel in the Home Ribbon. Click on the add-in in the Ribbon to open it.

## Login in the Add-in

Login with your Peliqan username & password. When you have 2FA enabled, login with your API token instead. You can find an API key in Peliqan under:

- Go to **Admin > Settings > API token** (access for Account Admins only): this is an account-wide API token with access to all tables in the account.
- Click on the **User icon in bottom left corner > User Settings > API token**: this is your personal API token with permissions defined by the groups that you belong to in Peliqan.

Click on "Generate API token" if you don't have a token yet.

![Generate API token in Peliqan](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/6a269b16-b453-4d0a-ac4d-86516b7617d9/Screenshot_2024-06-14_at_15.43.08/w=1920,quality=90,fit=scale-down)

## Sync data into Excel

Once you are logged in inside the add-in, you will see a list of tables and queries that are available to you:

![Excel add-in tables list](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/f4c8a84c-31f5-4761-a68c-0631e97a522c/Screenshot_2024-06-14_at_15.46.44/w=1920,quality=90,fit=scale-down)

Select a table in the drop-down and click on Sync data, to get real-time data into the current Sheet in Excel. You can repeat this to get updated data. The current Sheet will always be over-written with the new updated data:

![Sync data into Excel](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/1469f5d1-d4ab-4d6e-8dd7-daea0f44e530/Screenshot_2024-06-14_at_15.48.44/w=1920,quality=90,fit=scale-down)

As a best practise, do not edit the data in this Sheet. Instead use other Sheets in Excel to create e.g. reports, and use `VLOOKUP` formulas to fetch data from the data sheet.

## Keep multiple sheets up-to-date

When you select a Table and click on the "Sync data" button, the add-in will remember your choice. Next time when you open your Excel file and go to the same Sheet, the mapped table will be remembered and automatically selected.

You can add mappings in multiple sheets in Excel, and click the button "Sync all sheets", to keep all the sheets updated with a single click of a button:

![Sync all sheets in Excel add-in](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/40779d21-f290-4fcc-99cf-5ba040ae177a/Excel_add-in_sync_all_sheets/w=1920,quality=90,fit=scale-down)

## Sync multiple tables to the same sheet

You can sync multiple tables from Peliqan to the same sheet in Excel, by clicking the "+ Add table" button. Configure a different Start call for each table and make sure the resulting data will not overlap:

![Sync multiple tables to same sheet](https://images.spr.so/cdn-cgi/imagedelivery/j42No7y-dcokJuNgXeA0ig/390a86bd-6ad0-467e-ad87-8396f2fafef4/Excel_add-in_multiple_tables_on_one_sheet/w=1920,quality=90,fit=scale-down)
