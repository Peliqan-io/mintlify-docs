The Peliqan market place provides single-click deployment and hosting of common data tools such as Metabase (self-service BI tool), as well as information on how to connect external tools to Peliqan.

In Peliqan, click on the "Market place" icon in the left pane.

<img
  src="/images/Market place install Metabase etc/Screenshot_2026-02-20_at_17.57.53.png"
  alt="Peliqan market place icon"
/>

Click on a tool that you want to use for more information.

For tools that can be installed from Peliqan, the link will change to "Installed" once installation is completed. You can click the link to open the Web UI of the tool and proceed with the configuration.
