_Zoho Creator is **a low-code application development platform** that allows users to create custom business applications without extensive programming knowledge. It is an online application builder featuring an intuitive drag-and-drop interface that allows you to create custom applications effortlessly. This cloud-based database solution empowers organizations to design tailored applications, automate workflows, and securely store application data. Zoho creator can be integrated with multiple third-party software such as Zoho Apps, Google Apps, QuickBooks, Paypal and Salesforce._

This article provides an overview to get started with the **ZOHO Creator** connector in **Peliqan**. Please [contact support](https://peliqan.io/contact) if you have any additional questions or remarks.

## Zoho Creator Data Pipeline

### Connect Zoho Creator

Connect Zoho Creator through the Peliqan Connectivity Module:

<img
  src="/images/Zoho Creator - Getting started in Peliqan/image.png"
  alt="Zoho Creator connection form in Peliqan"
/>

Configuration Options:

1. **Account Owner Name :** Owner name present in the URL after Domain.
2. **Application Link Name :** App name present at the end of App instance URL.

<img
  src="/images/Zoho Creator - Getting started in Peliqan/image 1.png"
  alt="Zoho Creator URL showing account owner name and application link name"
/>

5. **Domain :** Country domain where the account instance has been created.
6. (Optional) **Report Name :** Comma-separated list if report name to data fetch for.
7. (Optional) table selection via '**Advanced**'

Once filled, Start the oAuth connection flow by selecting "**Connect Zoho Creator"** :

- Provide your username and password.
- Authorize Peliqan to access your data.

Data will be synced to the chosen data warehouse and made available through the Peliqan UI for exploration.

## Zoho Creator Data Activation

### Data API Endpoints

#### Get all form Fields

- With "Get Form Fields" function under Zoho Creator, one can fetch fields related to form available in Zoho Creator. Form_link_name has to be provided.
- This function is useful for viewing all available fields when creating records in a Zoho Creator Form.

<img
  src="/images/Zoho Creator - Getting started in Peliqan/image 6.png"
  alt='Zoho Creator "Get Form Fields" function in Peliqan'
/>

#### Get Records by Id

- With "Get Record" method provides details of record by id under any report. _report_link_name_ and _record_id_ has to be provided.
- This function is useful for viewing available record data when updating records in a Zoho Creator report.

<img
  src="/images/Zoho Creator - Getting started in Peliqan/image 7.png"
  alt='Zoho Creator "Get Record" function in Peliqan'
/>

#### Add Records in Zoho Creator

- "Add records" function allows to create records in Zoho Creator Instance.
- Simple process is to fetch all fields and create a object payload to be created.

<Accordion title="Related Script">
  ```python
  # Required Inputs
  report_link_name = "All_Orders"
  form_link_name = "Customer_Order_Form"
  
  # Required Connection
  dbconn = pq.dbconnect(pq.DW_NAME)
  zoho_creator_api = pq.connect('Zoho Creator')
  
  
  # Fetching fields of the form
  form_fields = {
      'form_link_name': form_link_name
  }
  result = zoho_creator_api.get('form_fields', form_fields)
  # st.json(result)
  
  # analyze the fiel available in form and type of fields.
  
  # Creating Record through form
  records = {
    'payload': {
        'Customer_ID_Admin_Only': '7634',
        'Email_Admin_Only': "test@example.com",
        'Support_Ticket_ID': "2930",
        'Product_Name': "RehaVib",
        'Purchase_Date': "10-Jan-2020", # date field
        'Ticket_Status': 'Open', # single choice field
        'Account_Status_Admin_Only': "Inactive",  # single choice field
    },
    'form_link_name': form_link_name,
  }
  result = zoho_creator_api.add('records', records)
  st.json(result)
  ```
</Accordion>

#### Update Records in Zoho Creator

- "Update Records" function allows to update records in Zoho Creator Instance.

<Accordion title="Related Script">
  ```python
  # Required Inputs
  report_link_name = "All_Orders"
  form_link_name = "Customer_Order_Form"
  record_id = '258987000000009003'
  
  # Required Connection
  dbconn = pq.dbconnect(pq.DW_NAME)
  zoho_creator_api = pq.connect('Zoho Creator')
  
  # Fetching object by record_id
  records = {
      'record_id': record_id,
      'report_link_name': report_link_name
  }
  result = zoho_creator_api.get('records', records)
  st.json(result)
  
  # updating values and updating record in Zoho creator
  records = {
      'payload': {
          "Account_Status_Admin_Only":"Inactive",
          "Email_Admin_Only":"test@example.com",
          "Delivery_Status":"In Transit",
          "Support_Ticket_ID":"2930",
          "Product_Name":"RehaVib",
          "ID":"258987000000009003",
          "Customer_ID_Admin_Only":"7634",
          "Ticket_Status":"Open",
          "Purchase_Date":"11-Jan-2020"
      },
      'record_id': record_id,
      'report_link_name': report_link_name
  }
  result = zoho_creator_api.update('records', records)
  st.json(result)
  ```
</Accordion>
